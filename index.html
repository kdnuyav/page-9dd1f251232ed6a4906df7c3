使用场景

日常浏览与远程办公

需要打开海外文档、代码托管、邮件和视频会议时，优先看稳定性和同时在线设备数。基础版适合单人、少量设备；若手机、笔记本和平板经常一起在线，旗舰版的 5 台设备更从容。

流媒体与长时下载

连续观看或大文件传输更吃流量和线路类型。旗舰版标明全节点原生流媒体解锁，适合把观影和普通上网放在同一订阅里；只做轻量浏览则不必为用不到的额度付费。

游戏与小团队

游戏加速看重时延和专线质量。旗舰版包含 IPLC 专线游戏优化，仍受游戏服务器位置和本地宽带影响，不能理解为所有区服都同样低延迟。团队版面向 20 台设备、1000GB 月流量，并支持企业定制路由和专属客户经理，适合工作室共用一个订阅而不是每人各买一份。

客户端选择

选客户端先看操作系统和是否需要规则分流，再看订阅格式是否匹配。下列为常见搭配，下载入口以本页锚点汇总，实际安装请走你信任的应用商店或项目发布渠道。

Windows

优先选择支持订阅链接、可手动切换节点、能看到当前连接日志的桌面客户端。办公电脑建议开启系统代理或虚拟网卡二选一，避免两种接管方式同时打开造成浏览器走了代理、其他软件却没有。

macOS

iOS 与 Android

手机端重点是后台保活、电池策略和是否允许局域网设备直连。蜂窝网络与 Wi-Fi 的 DNS 可能不同，切换网络后若突然无法打开网页，先在客户端内重连一次，再检查订阅是否过期。

移动端客户端说明

怎么判断选对了

能导入机场订阅、能显示节点延迟、能一键切回直连，并且设备数不超过套餐上限，就是合适的客户端。不需要为了“更多按钮”安装来源不明的修改版。

操作说明

导入订阅

  1. 在账户页复制当月有效的订阅地址，只保存在自己的密码管理工具或客户端里。
  2. 打开已安装的客户端，选择从 URL 导入或更新订阅，等待节点列表出现。
  3. 先选一个延迟较低的节点做网页测试，确认浏览器能打开目标站点，再切换到流媒体或游戏用途的节点。
  4. 设备数接近上限时，先在旧设备退出登录或关闭客户端，避免新设备提示在线名额已满。

流量与线路习惯

视频和系统更新最容易在短时间用掉额度。可以把系统更新留在直连，把必须中转的网站放进规则。旗舰版的专线更适合对时延敏感的游戏，普通浏览继续用普通节点，能把高价带宽留给真正需要的时段。

连接失败时按这个顺序排查：订阅是否过期、本地时间是否准确、客户端是否被安全软件拦截、当前网络是否禁止 UDP。更换节点前先看客户端日志里的最后一条错误，比反复重装更有效。

常见问题

GPT中转和只装一个加速器有什么不同？

加速器客户端负责在本机建立连接，GPT中转提供的是机场订阅、流量额度和线路。没有有效订阅，客户端只能停留在未配置状态；只有订阅、没有合适客户端，也无法在手机或电脑上实际启用。

基础版够不够日常使用？

若主要是网页、邮件和偶尔视频，3 台设备与每月 100GB 通常够单人使用。经常 4K 播放、多人共用或需要优先工单时，再看旗舰版或团队版，避免先买最小套餐后反复升级。

旗舰版的流媒体解锁是否等于所有片库都能看？

不是。套餐写明的是全节点原生流媒体解锁，指线路策略按流媒体站点做了区分。片库仍受账号地区、版权和平台风控影响，订阅不能改写这些平台规则。

游戏加速应该买哪一档？

明确有游戏需求时选旗舰版，因为它包含 IPLC 专线游戏加速优化。实际手感还取决于本地运营商、游戏服务器位置和当时负载。团队若多人同时开黑并共用额度，再评估团队版的设备数和带宽。

订阅链接可以发给朋友吗？

不建议。链接等同于流量和在线名额。多人共用会挤占设备数，也可能触发异常登录。团队使用应走团队版，并由管理员分配，而不是转发个人订阅。

官网下载后仍然无法更新节点怎么办？

先确认客户端版本支持当前订阅格式，再在客户端里手动更新一次订阅。若提示证书或时间错误，校正系统时间后重试。仍失败就保留错误原文提交工单，旗舰版为 7x24 优先处理，其他套餐按普通队列。
